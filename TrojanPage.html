What is a Trojan?

A Trojan Horse is a type of malware Malware is software designed to restrict, destroy, or force unauthorized access to a computer. that is disguised as a legitimate program A set of ordered operations for a computer to perform. so that it appears users installed malware on their devices of their own accord. Unlike worms Standalone malware that can replicate independently to facilitate the spread to other computers across a network. and viruses Software program that interferes with the operating system of a computer and needs to be activated by a host. , Trojans do not self-replicate. Typically called a "trojan virus," which isn't accurate, as a virus is a program that attaches itself to other software, while a Trojan is a program that conceals its true malware content to fool users. Usually distributed through social engineering A manipulation technique that involves tricking people into sharing sensitive information. , e.g., phishing A method of acquiring confidential information by taking some sort of action e.g clicking a link. .



Types of Trojans:



What is a Dropper Trojan?

A type of Trojan that can't execute code itself so brings other malware with it. Droppers already contain the other malicious components in the program package so they can be remotely updated in secret like Downloader Trojans so virus scanners will not be able to detect them with new definitions.

What is a Downloader Trojan?

Targets an already infected device. Downloaders need network resources to pull malware from the network, whereas droppers don't. It downloads and deploys more malicious code such as ransomware or keyloggers. Often the first stage of a multi-trojan attack, followed by installation.

What is a Rootkit Trojan?

A Trojan that conceals itself on a user's computer to prevent detection by other malicious programs. It allows attackers to acquire root-level access to a machine and boots together with the operating system, making it difficult to detect and remove.

What is a DDoS Trojan (Botnet)

A Trojan that turns devices into zombies for a larger botnet. The attackers objective is to harvest as many machines as possible and use them to flood servers with fake traffic. Most owners of infected computers are not aware that their devices are part of a wider network of other infected computers controlled by a amlicious user.





How to detect a Trojan Infection?

- Your computer is running way slower than usual. Trojans tend to come with additional malware that consumes significant (CPU) and memory which can make your computer unstable and sluggish.

- The appearanc of applications and softwares you do not recall downloading. In Windows Task manager, the appearance of an unfamiliar app from an unidentified developer can suggest malicious software has been installed.

- You experience consistent operating systems crashes and freezing, internet redirects, applications won't start and popups are so frequent you can barely use it. Trojans can manipulate browsers and modify key system settings.

- The blue screen of death is a windows error screen that declares that the system can no longer operate safely due to a hardware failure of the termination of an important process.




Case Studies:


Agent Tesla 2020

Agent Tesla, a keylogger and remote access malware, exploited the COVID-19 pandemic. It spread via PDFs, Word docs, and spreadsheets, capturing keystrokes, screenshots, and credentials from web browsers.

Agent Tesla Prevention

- Be cautious of email attachments during crises.
- Disable Macros in Microsoft Word.
- Use Multi-Factor Authentication (MFA).

Emotet Attack (2018)

Emotet, initially a banking Trojan, evolved into a malware distribution service. It infiltrated city systems, causing $1M in damages and affecting police and banking operations.

NjRAT (2018-2019)

NjRAT was used in cyber-espionage targeting governments and businesses in the Middle East and Europe. It enabled attackers to control infected systems remotely.

How to protect yourself from a Trojan threat.

- Never download or install software from unreliable sources.
- Never open an attachment or run a program sent to you in an email from someone you don’t know.
- Keep all software on your computer up to date with the latest patches.
- Make sure a legitimate antivirus is installed and running on your computer.
- For safe internet browsing, always keep a firewall up and running.
